我们很高兴正式向大家介绍 **Openfoot Manager**：一款免费、开源的足球管理模拟游戏。

## 什么是 Openfoot Manager？

Openfoot Manager 是一款桌面游戏，你将扮演一家足球俱乐部主教练的角色。你需要做出战术决策、管理阵容、处理财务、招聘员工、配置训练，并观看比赛逐分钟展开。一切都由使用 Rust 编写的复杂比赛引擎驱动。

与商业替代品不同，Openfoot Manager 具备以下特点：

- **100% 免费且开源**：基于 GPLv3 许可证发布
- **完全离线**：无需联网，没有云服务，也没有 DRM
- **可模组化**：使用外部 JSON 数据文件来创建自定义联赛、球队和球员
- **轻量级**：基于 Tauri 的桌面应用，二进制体积小巧

## 到目前为止的旅程

这个项目始于 2020 年，当时它只是一个 Python 业余项目，灵感来自经典的开源足球经理游戏 [**Bygfoot**](https://bygfoot.sourceforge.io/new/)，当然也少不了 [**Football Manager**](https://www.footballmanager.com/)。经过多轮迭代以及一次完整的 Rust 重写后，这款游戏已经发展成为一个带有 React 界面的现代桌面应用。

## 接下来会做什么

我们目前正处于积极的早期开发阶段，目标是不断推进并完善首个公开 alpha 版本。核心系统已经可以运行了，包括比赛模拟、阵容管理、训练、员工、财务、转会等等。接下来我们的重点会放在打磨整体体验和扩展功能集上。
